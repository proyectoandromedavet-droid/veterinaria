PENDIENTES DE SEGURIDAD
=======================

Punto 3 — Docker con usuario no-root
--------------------------------------
Los contenedores actualmente corren como root. Si hay una vulnerabilidad RCE,
el atacante obtiene privilegios de root dentro del container.

QUÉ HACER:
En cada Dockerfile de los servicios, agregar antes del CMD:

    # Crear usuario sin privilegios
    RUN addgroup --system --gid 1001 nodejs \
     && adduser  --system --uid 1001 nodeapp

    # Cambiar ownership de los archivos de la app
    RUN chown -R nodeapp:nodejs /app

    # Correr como usuario restringido
    USER nodeapp
